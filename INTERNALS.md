# nexttuesday.art, round 3: the shared layer and the reference

How the site is put together, for whoever builds or changes a variant. The
visitor-facing facts (what NTS is, the copy) live in the memex corpus; this
file is about the code.

The reference is Orbit, the variant Ome chose in round 2, rebuilt at
`site/_base/` on the round 3 foundation: Fraunces and Instrument Sans as
the default type, IM Fell inside INTERSECT only, one favicon, a nav that
keeps its font on every page, the world bleed-in in place of night-fall,
and plain handovers where the orbit arcs were. The variants of round 3
copy `_base` and explore one question on it: how sections hand over to
each other.

## Layout of the repo

```
site/
  _nts/            the shared layer. Variants link to it and never edit it.
    nts.css        tokens, ground, type, sigils, header, footer, sections,
                   lift, ledger, draw-in, the bleed-in, mega-sigil
    nts-head.js    runs in <head>: html.js, and the bleed's before/world state
    nts.js         header state, draw-in, the bleed-in, mega-sigil tap
    sigils.svg     the sigil sprite (generated by tools/gen-sigils.mjs)
    parts/         mega-sigil.svg and the still frames (inlined by sync)
    content/       site.json, events.json, copy.json: the one content source
    worlds/        one kit per initiative
      embers.css   embers.js (the hearth; also the fragment)
      philo.css    penrose.js (geometry) + philo.js (the entity; also the fragment)
      intersect.css ascii.js (the ASCII solid; also the fragment)
  _base/           the reference site (Orbit): index.html, embers/,
                   not-not-philo/, intersect/, events/; base.css (the world
                   pages' flow), orbit.css and orbit.js (the orrery home,
                   the compass, falling into a world)
  _variants/       the switcher pill (another agent's; every page loads bar.js)
tools/
  sync.mjs         fills the shared regions of every page from _nts/content
  gen-sigils.mjs   writes _nts/sigils.svg
  gen-stills.mjs   writes _nts/parts/still-*.{svg,txt}
```

## Making a variant

1. `cp -r site/_base site/<slug>`.
2. In the copy, replace the prefix: `grep -rl '/_base/' site/<slug> | xargs sed -i 's#/_base/#/<slug>/#g'`.
   That rewrites the internal links and the `<link href="/_base/…css">`.
3. `node tools/sync.mjs site/<slug>`. The script derives the prefix from the
   folder, so the generated header, footer and ledger links point into your
   folder.
4. Change the handovers: `site/<slug>/orbit.css` and `base.css` (rename them
   if you like) and the HTML. On the home page the hook is
   `<div class="handover" aria-hidden="true"></div>` between sections (a
   dotted plumb line in `_base`); inside the worlds it is the bands and the
   section edges. Everything under `site/_nts/` stays as it is. If you need
   something in the shared layer changed or added, write it down in your
   report with the selector or API you wanted; do not patch `_nts/`.
5. Run `node tools/sync.mjs site/<slug>` after every edit to a page, and
   `node tools/sync.mjs --check` before you hand over (exit 1 means a page
   is out of date).

What a variant may do inside its own folder: any layout, section order,
transitions, scroll choreography, its own CSS and JS, extra classes on the
shared markup, different `--section`/`--gutter` values on `:root`, a
different arrangement of the fragments, its own form for the bleed-in
(below), a `data-bleed="time"` page. What it must keep: the orrery (sun,
beads on their orbits, the events star), the windows into each world as
you scroll, the compass, falling into a satellite, the EMBERS tetrahedron
at its size and its section rhythm, NOT NOT PHILO's rings and triangle;
the header and footer regions (the skeleton on every page), the copy slots
and ledger regions (so sync works), the type roles, the world tokens
(restyle through `--w-*`, do not hard-code colours), the hard rules below,
and `<script src="/_variants/bar.js" defer>` last in `<body>` with the
bottom 64px free of fixed UI.

Hard rules for every page: static HTML that reads with JS off; Google
Fonts only, one `<link>` per page with only the families that page uses;
no Solstice, farm, WhatsApp, payment links or personal names; no RAVEMBER
2026 date or venue; English; copy only from `_nts/content/copy.json`;
`<title>`, description, og:title, og:description, theme-color, the one
favicon (the NTS sigil on coral, the same `<link rel="icon">` on every
page); no horizontal scroll at 320/360/390; 16px minimum gutter; AA
contrast, settled and at every frame of a transition; functional text 11px
or more; canvases cap DPR at 2, pause off-screen and in hidden tabs, and
draw one still under prefers-reduced-motion.

## Page skeleton

```html
<html lang="en">
<head>
  … meta, title, the one favicon, the page's Google Fonts link …
  <link rel="stylesheet" href="/_nts/nts.css">
  <link rel="stylesheet" href="/_nts/worlds/<world>.css">   <!-- the page's world, or all three on home -->
  <link rel="stylesheet" href="/<slug>/base.css">
  <link rel="stylesheet" href="/<slug>/orbit.css">
  <script src="/_nts/nts-head.js" data-bleed="scroll"></script>   <!-- data-bleed only on a world page -->
  <script src="/_nts/nts.js" defer></script>
  … world scripts, deferred …
</head>
<body data-world="embers">          <!-- nts | embers | philo | intersect; home adds data-nts-home -->
<!-- nts:sprite --><!-- /nts:sprite -->
<!-- nts:header --><!-- /nts:header -->
<main>…</main>
<!-- nts:footer --><!-- /nts:footer -->
<script src="/_variants/bar.js" defer></script>
</body>
```

`data-world` on `<body>` picks the world's tokens. It also works on any
element: a `<section data-world="embers">` on the home page is in EMBERS'
world (ground, text, accent, selection), which is how the windows into the
worlds are built. Do not put `data-world` on things that are merely about
a world; the ledger rows use `data-of` for that reason.

## Tokens (`nts.css`, section 1)

NTS palette: paper `#f4ecdc`, paper-2 `#ebe1cc`, ink `#1a1530`, ink-soft
`#5b5577`, coral `#f04a3a` (fields, marks, type at 24px and up; 3.1:1 on
paper), coral-ink `#c42b1f` (coral for small text, 4.8:1), gold `#f5b31b`,
cobalt `#2f3fd9`. Worlds: EMBERS night `#0b0709`, fire `#e51d47`, ember
`#f2591b`, cream `#ffe9d0`; NOT NOT PHILO ground `#e6e6e8`, ink `#2b2d3e`,
red `#e5174a`, key red `#e81e4c` (`--philo-red-key`, only for `.philo-key`:
3:1 on the grey and on the word's own charcoal plate; `--philo-red` stays,
since white on the bar needs it that dark); INTERSECT black `#0a0a0a`,
phosphor `#e9e2cf`, fire-hi `#ff3b63`.

The skeleton reads only the `--w-*` tokens: `--w-bg`, `--w-bg-2`, `--w-fg`,
`--w-muted`, `--w-accent` (shapes and large type), `--w-accent-text` (small
text), `--w-link`, `--w-line`, `--w-line-strong`, `--w-selection`,
`--w-selection-fg`, `--w-bar-bg`, `--w-bar-fg`. A world kit redefines them
under `[data-world="…"]`, once: the day sets of round 2 are gone, since
the state before the bleed-in is the NTS set itself (section 11 of
`nts.css`). Style your variant through them.

Type, five families, each with one job:

- `--font-display`: Fraunces, the display face. `h1`, `h2`, `h3`,
  `.display`, the wordmark, the ledger titles, the sign-off. Its axes come
  from role tokens: `--fraunces-display` (`"opsz" 144, "SOFT" 40, "WONK" 1`,
  cut sharp) on headings, `--fraunces-voice` (`"opsz" 48, "SOFT" 100`) on
  the italic voice (`.incant`, `.whisper`, the reveals, `.fig`), and
  `--fraunces-small` (`"opsz" 24, "SOFT" 50`) on the wordmark, the ledger
  titles and the contact line. Weights: 700 for `h1`, 600 for the rest,
  400 for the italics.
- `--font-text`: Instrument Sans, the text face. Body, `.lede`, `.label`,
  the nav, `.go`, the ledger's chips.
- `--font-intersect`: IM Fell DW Pica, only inside `[data-world="intersect"]`:
  its body text, its title, its headings and its italics (`intersect.css`
  resets the Fraunces axes there). It does not touch the nav or the
  wordmark.
- `--font-flyer`: Archivo, variable width 100..125 and weight 600..900,
  for the two worlds that brought their own display voice: EMBERS'
  extended caps (`.embers-display` at `"wdth" 125`, its labels and genres
  at 112) and NOT NOT PHILO's poster bold (`.philo-key`, `.philo-bar`, the
  volume titles, the band heading).
- `--font-mono`: Red Hat Mono: dates, EMBERS' bar and hint, INTERSECT's
  labels, tables and the ASCII solid.

Sizes of the main levels: `h1` clamp(2.6rem, 10vw, 5.5rem) (the home title
clamp(2.6rem, 11.5vw, 5.5rem)), `h2` clamp(1.9rem, 5.5vw, 3rem), `h3`
clamp(1.3rem, 3.4vw, 1.65rem), `.incant` clamp(1.25rem, 3.4vw, 1.75rem),
`.lede` clamp(1.15rem, 2.6vw, 1.35rem), body 1.0625rem, `.label` .72rem.
Each page's Google Fonts link carries only the families it uses: the home
loads all five; EMBERS and NOT NOT PHILO load Fraunces, Instrument Sans,
Archivo and the mono; INTERSECT Fraunces (the wordmark), Instrument Sans,
IM Fell and the mono; Events Fraunces, Instrument Sans and the mono. Add a
family to a page's link if you use it there.

Space: `--gutter` (16px floor), `--wrap` 72rem, `--section`, `--bar-h`.
Motion: `--ease-lift`/`--dur-lift`/`--lift-y` (the chooser's card lift,
exactly: `ease`, 250ms, -4px), `--ease-out`, `--ease-turn`, `--dur-draw`,
`--dur-bleed` (the bleed-in, below).

## Components

Sigils. Six symbols in the inline sprite: `#sigil-nts` (ring, heptagram,
point), `#sigil-embers` (fire triangle, three waves), `#sigil-philo` (the
impossible triangle), `#sigil-intersect` (crossroads in a broken ring),
`#sigil-star` (the ✴︎, for events and links), `#sigil-gathering`
(Tuesdays). Use:
`<svg class="nts-sigil sigil-embers" aria-hidden="true" focusable="false"><use href="#sigil-embers"/></svg>`.
`.sigil-<world>` sets the colour; `.lg` and `.xl` the size; inside `.go`
and `.nts-nav a` they size themselves. Every stroke has `pathLength="1"`,
which is what lets draw-in work with one dash rule.

Header and footer come from sync (`<!-- nts:header -->`, `<!-- nts:footer -->`).
The header is sticky, one row, 52px; on phones the wordmark hides and the
four destinations stay in one tap. It takes `--w-bar-bg`/`--w-bar-fg`, so
its colours follow the world; its type never does: the nav is Instrument
Sans 600 at .72rem (.7rem under 640px, .6875rem under 360px) on every page,
and `intersect.css` leaves it alone. The current page is marked by its
sigil before the label and a 2px bar in `--w-accent` right under the
label, 4px below the baseline (`.nts-nav a span::after`): the marker
belongs to the word, not to the bar's bottom edge, which is where round 2
had it floating. Hover and focus show the same bar faintly in the text
colour. Do not add a menu button or hide the header.

Sections: `.sect` (vertical rhythm), `.sect-head` (sigil + h2), `.rule`
(and `.rule.draw` to grow in), `.band` (a bold field: coral by default,
`.gold`, `.cobalt`, `.ink`), `.go` (a link that leads somewhere, with the
star), `details.reveal` (a whisper on tap).

The lift: add `.lift` to any block link or card. Hover and focus lift it 4px
on the chooser's easing, with a soft offset shadow; active presses it.

The ledger: `<!-- nts:events -->…<!-- /nts:events -->` renders every
event, upcoming then past, newest past first. Options on the open marker:
`upcoming` or `past` (one group), `world=embers` (one world), `limit=3`,
`heading=h2|h3|none`. Each row is `li[data-of="<world>"]` with the world's
sigil, a mono date, a Fraunces title (linked when the event has a page), a
`.kind` chip in the world's colour, the place and the line. Rows have ids
`ev-<id>` from events.json.

The mega-sigil: on the home page,
```html
<button class="mega-btn" type="button" aria-pressed="false" aria-label="Turn the sigil" aria-describedby="secret">
  <div class="mega"><!-- nts:mega-sigil --><!-- /nts:mega-sigil --></div>
</button>
<div class="turn"><p class="hint label" aria-hidden="true">Turn the sigil</p><p class="secret incant" id="secret">…</p></div>
```
It is complete from the first frame and its layers turn by themselves (CSS
animations, five speeds, two directions). With `html.js` the heptagram and
the three gold circles draw themselves in over the first three seconds and
the stars pop in; under reduced motion everything is simply there. A tap or
a long press aligns the layers (`.is-aligned`), opens the hole and shows
`.turn .secret`; a second tap resumes. Put it on a coral field: the colours
inside are the NTS tokens and assume coral behind them.

## The reference home (`orbit.css`, `orbit.js`)

The orrery: the mega-sigil is the sun on a coral disc, the sigils of the
three worlds and the events star ride orbits that continue its rings
(`.pivot` turns a zero-size point, the `.bead` on it stays upright), with
a key under the sky. Scrolling travels to each world: `section.world`
with `data-world` and `data-orbit-body`, its orb (`.orb`, holding the
world's live fragment) and its words; its ground blooms out of the orb
(`.world::before`, scroll-driven where `animation-timeline: view()` is
supported). Between the sections sits the handover, `.handover`, which is
the thing a variant replaces. The compass (`.compass`, fixed, bottom
right) shows once the sky has scrolled away and points at the nearest
body. Falling into a world is a cross-document view transition from the
body you tapped (`orbit.js` names it `orb`), into the world page's
`.hero .entity`, which carries the trace of the orbit.

## Behaviours

Draw-in. Put `data-nts-draw` on a container (its sigils and any `.drawn`
strokes draw themselves when it enters view) or on a `.nts-sigil` itself;
`data-nts-draw="fade"` fades and lifts the element instead; `.rule.draw`
grows from the left. Siblings in one parent stagger by 140ms through
`--draw-delay`. Everything is gated on `html.js`, so with scripts off (or
reduced motion) nothing is held back.

The world bleed-in. A world page loaded with
`<script src="/_nts/nts-head.js" data-bleed="scroll">` (or `"time"`)
starts in the NTS colours when the visitor arrived from the home page,
and its world's colours bleed in once. Landing directly, reloading, or
asking for reduced motion gives the world from the first frame. EMBERS'
bleed-in is its night-fall: paper to night.

- Detection, in `nts-head.js`, before paint: `nts.js` on a page whose
  `<body data-nts-home>` sets `sessionStorage["nts:from"] = "home"` when
  a link to `/…/embers/`, `/…/not-not-philo/` or `/…/intersect/` is
  clicked, and `nts-head.js` consumes it; failing that it accepts a
  same-origin referrer equal to the page's parent folder. It then sets
  `html[data-bleed="scroll|time"][data-bleed-state="before"|"world"]`.
- The before state is CSS: `html[data-bleed-state="before"] [data-world]`
  reads the NTS `--w-*` tokens (section 11 of `nts.css`), and each kit
  undoes what else its world brings (`--embers-glow`, `--hearth-base`, the
  penrose colours, `--grain`). Only three states exist: `before`, `in`
  (while the front runs) and `world`.
- The trigger: with `scroll`, the first real scroll past a third of the
  viewport; with `time`, after `data-bleed-after` ms on the script tag
  (default 2400).
- The crossing, in `nts.js`: a layer `.nts-bleed-front`, fixed to the
  viewport while it runs, carries the world's ground, clipped to a shape
  that grows with a progress `p` from 0 to 1 over `--dur-bleed` (1.6s,
  ease-out cubic). The tokens flip at once underneath, and every element
  holds an inline snapshot of its old colours (`color` where it has text
  of its own or sets its own colour; background, border, shadows
  everywhere) until the front reaches it. Text blocks are crossed in one
  jump: the front's progress is warped so the intervals they cover take no
  time. That is what keeps every frame readable; no colour is ever
  interpolated. Positions are read again on every frame, so a scroll still
  moving after the trigger carries elements across the front and each
  switches (or switches back) where it is; the front never rests inside a
  text block, so a fast scroll pushes it on in jumps. Text on a surface of
  its own (an ancestor with an opaque background, which hides the front)
  switches with that surface, not with the front. An image made of text
  (`[role=img]` with text of its own, INTERSECT's ASCII solid) is not a
  text block: the front crosses it like ground, through two copies of its
  glyphs (`.nts-bleed-glyphs`), old colours under the front and the
  world's over the page, clipped like the front. Elements still outside
  the viewport switch with the body's background at the end. Then the
  snapshots go, the front is removed, the state is `world`.
- Hooks, all on `window.NTS.bleed`, set before the trigger (a deferred
  script after `nts.js` is early enough):
  - `form`: `"sweep"` (default, top to bottom), `"disc"` (opening from the
    centre), or an object `{ clip(p, w, h), cover(box, w, h) }`. `clip`
    returns the front's `clip-path` at progress `p`; `cover` returns
    `[p0, p1]`, the progress at which the front first touches and fully
    covers a box `{x0, y0, x1, y1}` in the front's coordinates. One object
    defines both, so the switching stays in step with the shape: a wave is
    a `clip` whose edge is a polygon and a `cover` that reads the wave's
    band at the box's x.
  - `blocks`: an extra selector for elements to cross in one jump (by
    default anything with its own text, `.lift`, `.trace-bead`,
    `.nts-header`, `[data-bleed-block]`).
  - `duration`: ms, instead of `--dur-bleed`.
  - The event `nts:bleed` on `window`, with `detail { phase: "start" |
    "end", world, duration, at(el) }`: `at(el)` is the time in ms until the
    front reaches `el`, for anything that paints its own colours (the
    hearth and the triangle recolour themselves that way).
- Caveats: pseudo-elements cannot hold a snapshot, so a `::before` whose
  colour comes from a token flips when the tokens do; keep token colours
  on real elements or on fixed colours where it matters. A surface with
  its own `transition` on `background-color` or `color` would smear
  across the front: token-coloured surfaces get none.

## Fragments (for the home page)

One element per world, anywhere, any size (they are square):

```html
<div data-nts-fragment="embers"></div>      <!-- the hearth, small, 24fps, no embers, not interactive -->
<div data-nts-fragment="philo"></div>       <!-- the impossible triangle, 15fps -->
<div data-nts-fragment="intersect"></div>   <!-- the ASCII tetrahedron, 15fps; data-cols, data-figure -->
```

Sync fills each with a still (`.still`) so the page reads with scripts
off; the world's script adds the live layer and sets `.is-live`. They
inherit `border-radius` and take `--frag-bg` for the ground. They pause
off-screen and in hidden tabs. Load the three world stylesheets and
scripts on the home page (as `_base/index.html` does); the fragments need
them. For tuning, the same data attributes as the entities apply
(`data-spacing`, `data-size`, `data-spin`, …).

## The content source and sync

`_nts/content/copy.json` holds every line of copy, by key. In the HTML an
element carries `data-nts-copy="key"` and sync rewrites its inner HTML; a
`<meta … data-nts-copy="key" content="…">` gets its `content` rewritten
(tags stripped). `site.json` holds the nav, the footer, the handles.
`events.json` is the ledger (fields: id, date, display_date, title, kind,
world, place, line, status, link). To change copy or add an event, edit
the JSON, run `node tools/sync.mjs`, commit both. The text is also in the
HTML, so pages stay readable and greppable; the JSON wins on conflict.

Regions sync fills: `nts:sprite`, `nts:header`, `nts:footer`,
`nts:mega-sigil`, `nts:events` (with options), `nts:still <name>`, plus
the `data-nts-copy` and `data-nts-fragment` attributes. It only touches
what is between markers, and it is idempotent: `--check` is safe in CI.

Generated files, and how to regenerate them: `sigils.svg` from
`tools/gen-sigils.mjs`; `parts/still-*` from `tools/gen-stills.mjs` (it
requires `penrose.js` and `ascii.js` through node, which is why both
export `module.exports`).

## Verification that the reference passed

Phone 320, 360 and 390 on all five pages: scrollWidth equals innerWidth.
Console: no errors. In-browser contrast audit over every text node: all
AA, nothing under 11px, settled on every page and on three frames in the
middle of EMBERS' bleed-in. Bleed-in: `before` on arrival from home,
`world` after a third of a viewport, no inline styles left behind. The same
checks are expected of a variant; `tools/` has no test runner, so run the
screenshot script of your round and read the images.
